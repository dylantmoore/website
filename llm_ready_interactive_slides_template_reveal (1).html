From FOC to Decision Rule

Start with the FOC: $$\color{#60a5fa}{MB(x)} = \color{#f59e0b}{MC(x;\,\tau)}$$

We will walk term-by-term and then visualize the solution and how it shifts with a parameter \(\tau\).

From FOC to Decision Rule

$$\color{#60a5fa}{a - b\,x} = \color{#f59e0b}{c + d\,x + \tau}$$

Rearrange: $$\color{#60a5fa}{a} - \color{#f59e0b}{c} - \tau = (b + d)\,x$$

Decision rule: $$x^*(\tau) = \frac{a - c - \tau}{b + d}$$

Linear example for intuition; we will compute numerically (bisection) for general forms.
